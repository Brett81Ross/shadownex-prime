# ShadowNex Prime™
## Global Situational Intelligence

ShadowNex Prime is a proprietary browser-based OSINT/GEOINT command center built by Cactus🌵Byte Studios™. Version 2.2.0 is an independent ShadowNex-native implementation.

### Core systems
- **NexVision™** — interactive 3D globe and live intelligence layers
- **NexPulse™** — runtime feed health and source telemetry
- **PrimeScope™** — selected-object intelligence panel
- **ShadowLens™** — Normal / NVG / Thermal / CRT visual modes
- **NexCommand™** — typed/voice commands plus optional OpenAI briefing endpoint
- **NexDraw™** — marks, routes, measurements, areas and boundaries
- **PrimeCorrelate™** — cross-feed nearby-contact relationships
- **SceneDirector™** — target orbit, world sweep, route playback and clearly labeled launch reconstruction
- **Signal Share™** — native mobile sharing and ShadowNex QR links

### Runtime
Requires Node 22. No npm dependencies are required.

```bash
npm run dev
npm test
```
